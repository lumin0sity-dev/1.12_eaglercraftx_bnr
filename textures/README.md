# Texture Files

This directory contains item textures extracted from the Classic Faithful 32x - 1.21.1 resource pack for use with the WebGL texture injection system.

## Contents

### items/
Contains 46 item textures from Minecraft versions 1.13-1.21.1:

- **1.13-1.14 Items (5)**: trident, crossbow, suspicious_stew, sweet_berries, bamboo
- **1.15-1.16 Nether Update (11)**: All netherite tools, armor, and materials
- **1.17-1.18 Caves & Cliffs (22)**: copper items, amethyst, spyglass, glow_ink_sac, 17 candle variants
- **1.19-1.21 Items (8)**: recovery_compass, echo_shard, brush, mace, wind_charge, breeze_rod, trial keys

## Specifications

- **Format**: PNG images
- **Resolution**: 32x32 pixels
- **Total Size**: ~196KB
- **Source**: Classic Faithful 32x - 1.21.1 resource pack

## Notes

- `crossbow.png`: Extracted from `crossbow_standby.png` (base state)
- `recovery_compass.png`: Extracted from `recovery_compass_00.png` (first animation frame)

These textures are ready for use by the WebGL texture injection system to display modern Minecraft items in Eaglercraft 1.12.
